# AI Chatbot using LLMs

## Project Title
AI Chatbot using FastAPI, Streamlit and Free LLM

## Objective
To design and implement a full-stack AI chatbot application using modern AI tools and software engineering practices.

## Technologies Used
- Python
- FastAPI (Backend)
- Streamlit (Frontend)
- Free/Open-source LLM
- GitHub

## System Architecture
User → Streamlit UI → FastAPI Backend → LLM → Response → UI

## Features
- User-friendly chat interface
- FastAPI backend for handling requests
- Streamlit frontend
- Uses LLM to generate intelligent responses

## Steps to Run the Project
1. Clone the repository
2. Install dependencies using:
   pip install -r requirements.txt
3. Run backend:
   uvicorn main:app --reload
4. Run frontend:
   streamlit run app.py
